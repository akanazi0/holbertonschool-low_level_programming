# Recursion

This project focuses on the concept of recursion in C programming.

## What is recursion?

Recursion is a programming technique where a function calls itself to solve a smaller instance of the same problem. It is commonly used for tasks such as:

- traversing data structures
- solving mathematical problems
- implementing algorithms like factorial, Fibonacci, and binary search

## Key concepts

- A recursive function must have a base case to stop calling itself.
- Each recursive call should reduce the problem size.
- Without a base case, recursion can lead to infinite loops and stack overflow.
